# grindsemver

Grind identifiers and semver tokens for idempotent workflows.

**Site:** https://theworker02.github.io/grindsemver/

## Install / run

```bash
git clone https://github.com/theworker02/grindsemver.git
cd grindsemver
node src/cli.js
node --test
```
